# azur: интернет-магазин одежды на Astro и Cloudflare

Учебный магазин, сделанный с нуля вместе с Claude Code. Товары и бренд вымышленные, реквизиты продавца в коде пустые.

**Демо:** https://azur-shop.pages.dev (Cloudflare Pages: из части российских сетей не открывается, покажу на созвоне или пришлю скриншоты)

## Что умеет

- Каталог и карточка товара с размерами и остатками. Цены и остатки живые: страница собрана статикой,
  а при открытии сверяется с базой.
- Корзина, оформление заказа, доставка с подсказкой адреса.
- Личный кабинет: регистрация, вход, история заказов, сброс пароля.
- Оплата переводом по СБП: владелец получает заказ в Telegram и подтверждает кнопкой «Деньги пришли».
  ЮKassa в коде есть (создание платежа, вебхук, чек по 54-ФЗ), но не подключена.
- Админка для владельца: заказы и их статусы, товары, остатки, сводка.
- Письма покупателю и владельцу, проверка каналов уведомлений по адресу `/api/health`.

## Как устроено

| Часть | Что использовано |
|---|---|
| Витрина | Astro 7, Tailwind CSS 4, GSAP и Lenis для анимации |
| Сервер | Cloudflare Pages Functions (`functions/api/*.ts`) |
| База | Cloudflare D1 (SQLite), 11 миграций в `migrations/` |
| Уведомления | Telegram Bot API, почта через Resend |

## Решения по безопасности

- Из браузера принимаются только id товара, размер и количество. Цену и сумму сервер считает сам:
  иначе итог меняют в инструментах разработчика.
- Пароли хранятся как PBKDF2 с солью на каждого человека. 100 000 итераций подобраны замером:
  150 000 не укладываются в лимит процессорного времени бесплатного тарифа.
- Строки сравниваются за постоянное время, есть лимит попыток входа по адресу.
- Вебхук ЮKassa не верит телу запроса: статус оплаты перепроверяется запросом к самой ЮKassa.
- Адрес бота принимает запросы только с секретом в заголовке и только от владельца.
- Заказы фильтруются по пользователю в самом SQL-запросе, чужой заказ в ответ попасть не может.
- Админка закрыта отдельным паролем, сессии владельца хранятся отдельно от покупательских.

## Запуск

```bash
npm ci
npx wrangler d1 create azur        # id базы вписать в wrangler.toml
npx wrangler d1 migrations apply azur --local
npm run build
npx wrangler pages dev dist
```

Ключи задаются переменными окружения Cloudflare, в коде их нет:
`ADMIN_PASSWORD`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `TELEGRAM_WEBHOOK_SECRET`, `RESEND_API_KEY`,
`YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY`. Без них магазин работает в демо-режиме.
